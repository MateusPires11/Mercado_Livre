# Clone Mercado Livre

Um clone simplificado da página inicial do Mercado Livre, feito com HTML, CSS e JavaScript puro (vanilla JS), como projeto de estudo.

## 🌐 Demo

Veja o projeto ao vivo: [mateuspires11.github.io/Mercado_Livre](https://mateuspires11.github.io/Mercado_Livre/)

## 🚀 Funcionalidades

- Header com logo e campo de busca
- Grid de produtos renderizado dinamicamente via JavaScript
- Cards de produto com imagem, título, preço formatado e desconto
- Busca por nome do produto (via botão ou tecla Enter)
- Layout responsivo com Flexbox e CSS Grid

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica da página
- **CSS3** — estilização (Flexbox, Grid, transições)
- **JavaScript (Vanilla)** — renderização dinâmica dos produtos e lógica de busca
- **Font Awesome** — ícones (via CDN)

## ▶️ Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/MateusPires11/Mercado_Livre.git
   ```
2. Abra o arquivo `index.html` no navegador (ou use uma extensão como o Live Server no VS Code).
